# 폐기물 사진 12종 분류

폐기물 사진 한 장을 받아 의류, 신발, 유리, 플라스틱 등 12개 품목으로 분류하는 KDT 17기 3인 팀 프로젝트다. 나는 팀장으로 데이터 전처리를 맡았다. 모델을 바꿔도 의류를 신발로 분류하는 오류가 반복돼, 원본 이미지의 중복과 잘못 붙은 품목명을 먼저 점검했다.

## 결과

| 확인한 내용 | 비교 조건 | 결과 |
| --- | --- | --- |
| 라벨 정정 효과 | 같은 모델·같은 설정, 128 px, 검증 사진 2,318장 | 의류를 신발로 분류한 오류 **8건 → 3건**. 품목별 F1의 평균 **0.9629 → 0.9731** |
| 팀 최종 분류 모델 | EfficientNetV2-S, 224 px, 별도 시험 사진 2,334장 | **2,301장 정분류**, 33장 오분류. 정확도 **98.59%**, 품목별 F1의 평균 **0.9787** |

## 1. 중복 이미지 판별

같은 파일은 MD5로 골랐다. 크기를 바꾸거나 다시 저장한 사진은 dHash와 픽셀 차이로 후보를 좁혔다. 흰 배경의 서로 다른 칫솔까지 비슷한 사진으로 잡혀 직접 대조했다. 중복·라벨 충돌 등으로 31장을 제외해 원본 15,515장 중 15,484장을 남겼다. 유사 사진 25그룹은 같은 사진이 학습과 평가에 걸쳐 쓰이지 않도록 그룹별로 분할했다. [중복 탐지 방법](duplicate_detection_method.md)

## 2. 라벨 검수

확신도 0.9 이상으로 기존 라벨과 다르게 예측한 사진 204장을 육안으로 확인했다. 학습 사진은 두 묶음으로 나눠 해당 사진을 보지 않은 모델의 예측을 사용했다. 고친 라벨 46장 중 43장은 의류 폴더에 들어 있던 신발이었다. [검수 기록](label_review_report.md) · [정제 내역](data_cleaning_summary.md)
